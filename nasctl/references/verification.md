# 调研与验证记录

更新日期：2026-11-09。此处仅保留客户端验证方法，不记录私人实例的认证状态、站点/文件服务器数量、文件名、地址或其他部署快照。

## 已有验证依据

- 曾按目标实例的 OpenAPI 核对操作分类、搜索参数及分页字段。接口语义可能随版本变化，当前操作仍须通过实时 `operations` / `describe` 获取契约。
- 客户端的读写分类、写开关、同步 `dryRun` 布尔要求、添加任务的幂等键、重定向拦截及部分失败识别，使用隔离模拟接口测试。
- 文件索引、种子索引和运行中下载任务分别处理；空页、部分下载器失败和异步受理不能解释为没有数据或执行完成。
- 原验证工作区的测试位于技能项目之外，不随本仓库发布；历史通过记录不表示当前仓库自带测试套件。

## 未验证边界

- 本次发布审计不连接真实 NAS、数据库或下载站，不以业务写入测试公开安全性。
- 未以本次审计验证新增/移除下载、任务控制、站点变更、图片缓存、实际同步和队列清理的成功路径。
- 模拟接口保护不等同于用户授权，也不证明服务端不存在其他副作用。认证与网络访问方式必须按目标部署核对。
